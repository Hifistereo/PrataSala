# Prāta Piedzīvojumu Sala

Static kid-facing web game prepared for GitHub Pages.

## Deploying on GitHub Pages

1. Commit these files to a GitHub repository.
2. In the repository settings, open **Pages**.
3. Set the source to **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save the settings.

The game is served from `index.html`. Keep `support.js`, `Dragon.dc.html`, and `Prata Sala.dc.html` in the repository root with it.

No npm install or build step is required.
